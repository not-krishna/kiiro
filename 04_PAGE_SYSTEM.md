# 04 --- Page Templates

## Principle

Build a small number of strong templates.

Do not create bespoke React page implementations for every CMS document.

------------------------------------------------------------------------

# Template A --- Artform

Route: `/artforms/[slug]`

Sections:

1.  Hero
2.  What it is
3.  Where it comes from
4.  Cultural context
5.  Materials
6.  Technique/process
7.  Artisan
8.  Process gallery
9.  Contemporary relevance
10. Related experiences
11. Related events
12. Journal
13. Enquiry

## Cultural requirement

The page must be able to distinguish: - documented fact - artisan
voice - Kiiro editorial interpretation - contemporary context

------------------------------------------------------------------------

# Template B --- Experience

Route: `/experiences/[slug]`

Sections:

1.  Hero
2.  Who it's for
3.  Overview
4.  What participants do
5.  What they learn/experience
6.  Format
7.  Duration
8.  Location
9.  Facilitator/artisan
10. Gallery
11. Upcoming dates
12. FAQ
13. Enquiry

------------------------------------------------------------------------

# Template C --- Event

Route: `/weekly-events/[slug]`

Required: - title - date - time - location - city - related artform -
facilitator - description - price if applicable - capacity if
applicable - booking state - CTA

Never invent availability.

------------------------------------------------------------------------

# Template D --- Artisan

Route: `/artisans/[slug]`

Sections: - portrait - name - craft - place - lineage/story - practice -
teaching role - process gallery - quote - related experiences - impact

The page should feel like a person profile, not an employee card.

------------------------------------------------------------------------

# Template E --- Journal

Route: `/journal/[slug]`

Sections: - category - title - standfirst - author - date - hero - rich
content - pull quotes - image gallery - related artform - related
artisan - related experience - related articles

------------------------------------------------------------------------

# Template F --- Partnership / CSR

Sections: - problem - context - Kiiro approach - program structure -
artisan/community role - outcomes - examples - CTA

Do not promise measurable outcomes without evidence.

------------------------------------------------------------------------

# Template G --- Community

Creative Wellness Circle:

-   purpose
-   principles
-   who it's for
-   recurring experiences
-   upcoming events
-   member stories
-   join/enquire

------------------------------------------------------------------------

# Template H --- Learning

Support: - learning paths - beginner - intermediate - advanced -
certificates - related experiences

------------------------------------------------------------------------

# Template I --- Product

Support: - product - maker/artisan - materials - story - dimensions -
price if approved - availability - gifting context

Do not implement checkout until ecommerce scope is approved.
