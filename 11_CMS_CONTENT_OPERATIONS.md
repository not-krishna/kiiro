# 11 --- CMS Operations & Editorial Workflow

## Goal

A Kiiro team member should be able to manage the site without asking the
developer to edit code.

------------------------------------------------------------------------

# Publishing workflow

## Draft

Content is being written.

## Review

Content is ready for someone to check: - factual accuracy - image
rights - spelling - cultural context - CTA - SEO

## Publish

Only approved content is published.

------------------------------------------------------------------------

# Artform publishing checklist

Before publishing an artform:

-   [ ] title approved
-   [ ] region verified
-   [ ] cultural context verified
-   [ ] history/lineage source confirmed
-   [ ] artisan information confirmed
-   [ ] imagery approved
-   [ ] image rights confirmed
-   [ ] related experiences linked
-   [ ] SEO title
-   [ ] SEO description
-   [ ] alt text

------------------------------------------------------------------------

# Image governance

Every image should have:

-   meaningful filename
-   alt text
-   photographer/source if required
-   usage rights status
-   subject/context

Do not upload hundreds of duplicate images.

------------------------------------------------------------------------

# Content reuse

Do not copy the same paragraph into: - homepage - artform - journal -
experience

Instead: - create canonical content - reference it - write contextual
summaries

------------------------------------------------------------------------

# SEO content

The Journal must prioritize genuine editorial value.

Good: - artisan interviews - process stories - cultural context -
material knowledge - workshop documentation - responsible contemporary
craft

Bad: - "10 benefits of pottery" - keyword-stuffed cultural history -
generic AI-generated articles - rewritten Wikipedia-style filler

------------------------------------------------------------------------

# Localization

Sanity supports multiple locales/content types.

Do not implement multilingual content until: - target languages are
confirmed - translation workflow is defined - URLs are defined - SEO
strategy is defined

The architecture should not prevent it later.
